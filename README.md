# WPS SKU工具 v1.0.5 · 批量加速版

本版改用“批量读取 → 内存清理 → 批量写回”，解决v1.0.4虽不卡顿、但2万行处理太慢的问题。v1.0.4仍逐个调用WPS，每25个处理步骤等待40毫秒；2万行双SKU列的回归场景有8万次写入，配置等待约64秒。v1.0.5同一场景仅80次写入，约40个批量块，配置等待约0.33秒。以上是回归调用数及调度等待，不等于真实工作簿用时。

本机WPS原生接口已在可丢弃工作簿中验证：2万行×2列的批量读写与指定类型处理约0.25秒；数字、文字、公式形态文字的类型正确，错误和公式能够排除。此计时未执行完整JS加载项，不承诺你的文件一定同样耗时。

## 使用

1. 完整解压，双击 **Install-Offline.cmd**。若本机已由本次任务更新，无需再次安装。
2. **保存所有文件，完全退出WPS，再重新打开。** 旧版内存代码需退出后才会卸载。
3. “SKU工具 → 查看状态”确认版本 **v1.0.5**。点击“WPS内自测”，应提示 **WPS批量接口自测通过**。
4. 可点击 **2万行测速**。工具只新建未保存的测试工作簿，包含2万行、两列；完成时检查首尾值、数字/文字类型、格式、公式和计数，并显示实际用时。
5. 正常使用点击“处理当前表”或“处理所选区域”。需要整理后续输入/粘贴时，点击“开启当前文件自动处理”。

自动处理每次启动默认暂停；打开文件、切换表不扫描。自动模式仅绑定所选文件，不扫描其他文件。查看状态显示批量块数、兼容处理数量、用时及错误。“停止处理”取消后续批次和排队任务，保留已完成修改。工具不自动保存。

## 规则

| 内容 | 处理结果 |
| --- | --- |
| 含SKU的表头，如公司sku、平台SKU | 大小写不限，识别对应列 |
| `'2714230032211`、全角数字、带空白数字 | 清理后转数值，自定义格式 `0` |
| `000123` | 数值123，前导零去掉 |
| ` ' AB C-１２３ ` | 文本 `ABC-123`，格式 `0` |
| `ABC`、`001AB` | 保持字母大小写与文本类型，格式 `0` |
| `1E12`、`12.0`、`=1+2`、`1/2`等文本 | 保持文字，避免被解释为数字、日期或公式 |
| 超过15位有效数字的编号 | 原值和格式保留，避免精度损失 |
| 公式、错误、合并单元格、保护区域 | 保留或跳过 |
| 真正空单元格、非SKU列 | 不改值、不设置格式 |

清理空白、换行、常见隐藏字符和前置单引号，全角数字转半角；保留字母和其他符号。隐藏或筛选隐藏行也处理。

## 加速实现与边界

- 正常数据默认每次处理1000行。一次读取一列数组，在内存中分类清理；连续可处理行成批设置格式和写回。数字和文字混合时先按文本格式写入带类型的二维数组，再设置格式0。
- 用常量筛选排除公式和错误，超过15位有效数字、无效数字、空白也隔离，不把整列盲目覆盖为计算结果。
- 合并单元格、过于零散的区域或不支持批量接口的宿主，会缩小处理块，必要时使用受限的逐格兼容处理。状态中的“兼容处理单元格”可判断慢速原因。批量自测未通过时不会声称批量接口可用。
- 批量写入报错立即停止，不按逐格方式重试可能已部分写入的数据。已完成的修改保留。仅探测阶段允许兼容回退。
- 每次只执行一个数据块，批次间等待8毫秒；单次耗时超过80毫秒时缩小后续块。每批结束恢复事件与屏幕刷新；不跨批次关闭全局设置。单个WPS接口调用不能强制中断。
- 已整理的值和格式不会重复回写。批次内读写连续完成，不把前一批读取的旧数据延后覆盖用户新值。
- 表头检查前20行、前256列，取第一行含SKU的表头。一张表按一个主数据表处理。每个任务最多20万个SKU单元格，整文件最多100张表，选区最多32个区域；超限用较小选区分次操作。
- 用实际内容末行限制范围，避免遍历百万行空白格式尾部。仅修改表头、仅修改格式、公式重算不扫描已有数据，已有数据使用处理按钮。

大量公式、合并单元格、保护或零散数据仍可能比普通连续数据慢。真实用时受WPS版本、硬件、文件公式及加载项运行环境影响；以“2万行测速”和实际副本上的完成报告为准。

## 安装与开发

离线运行无需本地HTTP服务或Node.js。安装脚本备份配置、仅替换本工具，保留其他加载项和WPS许可/安全设置。如客户端出现正常许可提示，按WPS提示处理。

- `js/SkuCleaner.js`：分类、数组批量读写、兼容处理、范围及任务调度。
- `addin/adapter.js`、`addin/ribbon.xml`：加载、按钮、状态、批量自测和测速。
- `build.cjs`：运行 `node build.cjs` 后生成 `addin/main.js` 及 `offline/WPS-SKU-Cleaner_1.0.5/`；修改后重新安装和重启WPS。
- `tests/`、`VALIDATION.md`：运行 `node --test --test-concurrency=1 tests/*.test.cjs`。无需安装第三方依赖。
- `Install-Offline.*`、`Uninstall-Offline.*`：离线安装/卸载，只处理本工具。
- 在线安装文件仅作备用开发工具，日常不需要。独立JS宏需宿主支持定时器和批量接口；不要同时开启加载项和独立宏自动模式。
- VBA兼容源码仅支持少量手动操作，自动模式禁用、每次最多2000个SKU单元格。本版加速的是JS加载项，未编译或执行VBA。

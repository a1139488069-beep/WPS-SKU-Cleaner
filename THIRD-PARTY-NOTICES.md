# Third-party component

`vendor/wpsjsrpcsdk.js` is an unmodified copy of `wpsjs-rpc-sdk-new` version 1.1.0, retrieved from the npm registry on 2026-10-09. The distributed `sdk-package.json` retains the package metadata and its declared ISC license and author (`zouyf`). This archive did not include a separate license file.

Package source: https://registry.npmjs.org/wpsjs-rpc-sdk-new/-/wpsjs-rpc-sdk-new-1.1.0.tgz

The WPS official `wpsjs` 2.2.3 development package references this SDK as its installation/communication dependency. The SDK is used only by the installation page to communicate with the user's local WPS service. The SKU cleanup core has no third-party dependencies.
